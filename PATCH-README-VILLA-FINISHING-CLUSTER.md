## How to apply

Copy the contents of this ZIP into the Mawsooq project root, preserving folders and replacing the included edited files.

The existing build pipeline already runs `scripts/generate-arabic-routes.mjs`; the six source pages live under `app/_arabic-pages/`, so their public Arabic routes will be generated by the current build process.

Then run the normal project build. No database changes are required.

## Existing source dependencies intentionally reused

The patch imports the current repository's `@/lib/mawsouqProjects` data for:

- actual Mawsooq project pages and project images;
- Mawsooq's official YouTube channel;
- existing customer testimonial video IDs.

This keeps testimonials and work examples grounded in the site's current first-party data rather than hard-coding new marketing claims.
